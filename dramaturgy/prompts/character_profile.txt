請根據以下 Premise Contract 與 Framework DNA，為這個故事設計旁白/主角的語音特質與心理檔案。

注意：在短影音敘事中，「主角」通常是旁白者本身——一個有特定觀點和說話習慣的聲音。你要讓這個聲音有獨特的語氣、習慣用詞和說話節奏，而不是一個中性的資訊播報員。

{{premise_contract}}

Framework DNA：
{{framework_dna}}

你的任務：

1. protagonist_voice（語音特質）：這個旁白/主角說話的方式。
   - speech_pattern：慣用的句型結構和節奏（如：喜歡先說結論再解釋、習慣用反問製造停頓）
   - vocabulary_level：詞彙層次（如：日常口語為主、偶爾夾雜專業詞彙但會立刻解釋）
   - sample_phrases：3個最能代表這個聲音風格的範例短語

2. core_flaw（核心缺陷）：這個旁白聲音隱藏的認知侷限或執念（一句話）。
   範例：「相信只要努力就一定有回報，所以對不公平的結果格外憤怒」

3. hidden_motivation（隱藏動機）：這個旁白真正想讓觀眾「得到」什麼（一句話）。
   範例：「希望觀眾不要像自己一樣浪費了某段時間才明白這個道理」

4. cannot_say_directly（說不出口的事）：3個這個旁白/主角絕對不會直白說出口的內在狀態。
   這些情感必須透過行為、細節、停頓或側面語言來暗示，而非直白陳述。
   範例：「我曾經深信這個謊言」「這件事讓我現在還覺得有點羞愧」

輸出格式：
{
  "protagonist_voice": {
    "speech_pattern": "<語音模式描述>",
    "vocabulary_level": "<詞彙層次描述>",
    "sample_phrases": ["<範例短語1>", "<範例短語2>", "<範例短語3>"]
  },
  "core_flaw": "<核心缺陷（一句話）>",
  "hidden_motivation": "<隱藏動機（一句話）>",
  "cannot_say_directly": ["<說不出口的事1>", "<說不出口的事2>", "<說不出口的事3>"]
}

請只輸出 JSON，不含任何前言或說明。
